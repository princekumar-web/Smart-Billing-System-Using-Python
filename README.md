# Smart-Billing-System-Using-Python
Python Tkinter based Pizza Billing System

## Features
- Item selection
- Total calculation
- Bill generation with date

## Tech Used
- Python
- Tkinter

## ▶️ How to Run

Follow these steps to run the project on your system:

1. Install Python (version 3.x)  
   Download from: https://www.python.org/

2. Download or clone this repository  
   git clone https://github.com/your-username/pizza-corner.git

3. Open the project folder  
   cd Smart-Billing-System-Using-Python

4. Run the Python file  
   python smart_billing_system.py  
   (or use: py smart_billing_system.py)

5. The application window will open
